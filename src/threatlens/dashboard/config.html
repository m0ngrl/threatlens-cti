Configuration

Local settings stored in threatlens.conf. Saved changes apply to the next ingest, from here or the command line, without a restart. The file does not exist yet, so built-in defaults are shown; saving creates it.

Ollama

Server the LLM engine sends verification requests to. Batch size, context window and timeouts are in the file's [llm] section, which the calibration tool writes (python -m threatlens.extractors.calibration); saving here keeps them.

Quality weights

How much each 0-5 dimension counts toward an indicator's 0-100 quality score. Each between 0 and 1, and together they must total 1.00. Overrides the weights in the database's scoring_config table.

Verifier agreement

Confidence multiplier applied when the Python and LLM verifiers agree or disagree to each degree. 1.00 means no discount.
