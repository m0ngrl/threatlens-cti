How the deviation value is calculated

A report entry is one indicator sighted in one report, i.e. one row of the sightings table. Entries are matched across runs by report filename plus the indicator's (ioc_type, normalised) key. For each entry and each pair of runs, five components are scored from 0 (identical) to 1 (completely different):

ComponentSource fieldScore
LLM verdictscore_components.agreement.winning_status (confirmed / context / rejected)1 if different, else 0
Confidenceindicators.confidence (0–100)|Δ| / 100
Context fieldsindicators.context JSON (malware family, actor, TTPs, excerpt, …)share of keys whose value differs
Quality flagsquality_flags rows for the indicator (type + severity)Jaccard distance of the two flag sets
Stored valueindicators.value (as written, e.g. defanged or not)1 if different, else 0
entry deviation = mean(verdict, confidence, context, flags, value) 0 … 1 report deviation = mean(entry deviation over every entry in the report) run deviation = mean(report deviation over all reports) ← "average per report entry" three-way index = mean(ex2↔ex3, ex2↔ex4, ex3↔ex4) for the report

An entry that appears in only one run would score 1 on every component. None did. 2 reports have no stored sightings in any run (6b8d1b3f…, f14bf397…), so they are shown as n/a and left out of the averages, which therefore cover 101 reports.

Quality score is kept out of the LLM deviation on purpose. It is computed downstream from the scoring weights and from the date each run was scored (timeliness), not from the LLM. Folding it in would count configuration and calendar effects as LLM variance, so it gets its own section.

Only 97 of 6,239 entries score differently between ex2 and ex3/ex4, by 0.08 points on average. Two dimensions account for all of it:

  • Timeliness differs on 63 entries (52 indicators). It depends on when a run was scored: reports published just before ex2 was scored on 7 Oct had moved into an older age band by the time ex3/ex4 were scored.
  • Completeness differs on 34 entries (7 indicators), following the context-field changes in the LLM deviation above.

Accuracy and relevance are identical in all three runs. The two dimension counts are not additive: an entry can differ in both, and a change in one dimension can round to the same score.
